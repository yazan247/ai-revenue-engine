# AI Revenue Engine

## Product: InvoicePilot

InvoicePilot is a lightweight SaaS concept for small service businesses that need to follow up on unpaid invoices without spending hours writing reminders.

### MVP
- Create customers and invoices
- Track due dates and payment status
- Generate professional reminder messages
- Maintain a follow-up timeline
- Simple dashboard

### Commercial goal
Start with a low-cost subscription and validate demand before adding expensive infrastructure or complex integrations.
